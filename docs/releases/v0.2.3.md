# NextTraceroute 0.2.3

本次著重長網址輸入與追蹤流程穩定性。

- 貼上完整網址時先擷取主機名稱，網址路徑、查詢參數長度與非標準跳脫字元不再影響目標辨識。
- 移除可能造成堆疊溢位的網域正規表示式；加入網域長度、標籤長度、連接埠與 IPv6 格式檢查。
- DNS 的 IPv4／IPv6 結果集中去重後更新畫面，並處理只有 CNAME 的回覆與別名循環。
- 強化地理資訊 API 的空值、格式錯誤、斷線及延遲回覆處理。
- 停止追蹤時等待上一輪工作結束，關閉 WebSocket 並中止 ping，避免重跑時混入舊結果。
- 歷史紀錄查詢隨輸入取消，資料庫失敗或缺少可開啟連結／分享的 App 時顯示錯誤，不讓例外直接使頁面退出。

Android 8.0 以上可用；versionCode 21。保留 NextTrace 1.7.2 API 與既有正式版簽章，可覆蓋安裝更新。

測試使用的網址不含使用者提供的臨時授權參數。第三方 DNS／NextTrace 服務不可用或目的地主機不回應時，仍可能無法完成解析、取得地理資訊或顯示全部跳點。
