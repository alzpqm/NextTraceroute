# NextTraceroute 0.3.0

- 新增 NextTrace API v4 HTTP 地理資訊查詢，未設定 v4 授權時保留 v3。
- 在設定中開啟 NextTrace 官方授權頁，完成官網的人機驗證及確認後，自動驗證並匯入授權；此流程仍可能需要使用者互動，並非背景自動領取或自動續期。
- 使用 AndroidKeyStore 加密保存 token，排除授權與 WebView 資料的系統備份；授權畫面禁止螢幕擷取。
- 授權到期、無效或額度耗盡時明確提示；不會靜默降級至 v3，也不會自動反覆重領授權。
- 保留長 IPv6 自動換列、中文優先及英文切換。

Android 8.0 以上可用，versionCode 25。使用與既有正式版相同的簽章，可直接覆蓋安裝。

官網的 token 頁面、驗證流程、配額與 API 服務條件由 NextTrace 營運。取得 token 不代表第三方專案已完成服務授權確認。

驗證：37 項 JVM 測試、API 37／16 KB 模擬器 22 項回歸通過，最後授權畫面調整後再跑 2 項通過。OnePlus Android 14 首輪 21 項通過，解鎖後語言與授權 3 項補測通過；使用者完成官網驗證後自動匯入成功，另有 1 項實際 v4 授權狀態及 GeoIP 查詢測試通過。未測所有裝置、完整 7 天到期週期或真實配額耗盡情境；401／429 及取消等條件由受控測試驗證。
