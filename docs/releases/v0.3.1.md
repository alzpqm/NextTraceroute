# NextTraceroute 0.3.1

- 修正追蹤結果地區名稱的中英文混用：預設跟隨 App 介面語言，同一輪追蹤固定語言；可在「設定 → 結果地區語言」另外選擇中文或英文。
- v3／v4 共用雙語欄位選擇及國家名稱本地化，補齊香港、澳門、新加坡等已知地區別名，避免出現「中国 Macau」或中文結果夾雜「China Hong Kong」。
- 保留網域、主機名稱、ASN 與其他技術識別文字。無可確認譯名的地點保留來源名稱；既有歷史紀錄保留當時內容，不會自動改寫。
- 沿用 v4 官方驗證後自動匯入、加密儲存及既有授權；本次更新無需重新領取仍有效的正式版授權。

Android 8.0 以上可用，versionCode 26。沿用既有正式版簽章，可直接覆蓋安裝。
