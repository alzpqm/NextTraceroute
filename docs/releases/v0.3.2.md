# NextTraceroute 0.3.2

- 修正 0.3.1 缺少目標語言譯名時，仍把另一種語言接到結果中的問題，例如「Austria Vienna 维也纳」。有譯名的國家／省／城市繼續顯示；缺譯名欄位不再跨語言補值，原始雙語 metadata 仍保留於地圖資料。
- 追蹤結果地區名稱統一跟隨「設定 → 介面語言」，直接讀取 App 保存的選擇，每輪追蹤固定語言。移除獨立的「結果地區語言」，舊 API 語言設定不再覆蓋介面語言。
- 網域、主機名稱、ASN 與網路業者識別文字保留原文。既有歷史不改寫，請更新後重新追蹤。
- 新增經 MainActivity、保存設定、Activity 重建、MainWSHandler 到結果列的整合測試，使用 Debug 專用資料來源及本機回環；正式版不含可設定的測試資料來源。
- 保留現有正式版資料與有效 v4 授權，沿用既有簽章，可直接覆蓋安裝。

Android 8.0 以上可用，versionCode 27。
