# NextTraceroute 0.2.4

本次修正設定頁崩潰與地理資訊遺漏，並統一介面語言。

- 修正異常設定值（NaN、Infinity、超出範圍或非整數）可能使設定頁崩潰；無效數值改用安全預設值。
- 修正較晚出現的跳點未取得 ASN／地理資訊，也未納入地圖資料的問題。
- 修正後端不可用時，本地保留位址分類也消失的問題；本地分類不再依賴外部服務。
- 地圖請求加入整體逾時、回應大小限制及取消連動，避免慢速回應拖延停止追蹤。
- 中文（正體中文）為預設介面；設定中的第二個介面語言為英文（英式英文）。首頁、設定、歷史紀錄、提示與關於頁已統一翻譯，語言選擇在重新啟動後保留。
- 介面語言與 API 回應語言分開設定；兩種介面語言均隨應用程式提供，不需另外下載。
- 更正原生 ping 不可用時的提示，以及隱私權政策連結。

驗證：24 項 JVM 測試通過；Android 14 實機及 API 37／16 KB 模擬器各 13 項操作／回歸測試通過，包含長網址、停止重跑、旋轉、設定與語言切換。

Android 8.0 以上可用，versionCode 22，相容 NextTrace 核心／API 1.7.2。沿用既有正式版簽章，可直接覆蓋安裝；請勿先解除安裝，以免刪除本機紀錄。

第三方 DNS／NextTrace 服務不可用或目的地主機不回應時，仍可能無法解析、取得地理資訊或顯示全部跳點。本次測試不代表所有裝置及網路場景均無錯誤，未驗證 Google Play 上傳。
